# Fonts: Mohr Rounded

The app is wired to use Mohr Rounded. Drop your licensed font files into this
folder with these exact names and they activate automatically. Until they are
here, the app quietly falls back to Nunito, so nothing breaks.

Required files (either .woff2 or .otf works, .woff2 is lighter and preferred):

    MohrRounded-Light.otf         (or .woff2)
    MohrRounded-LightItalic.otf   (or .woff2)
    MohrRounded-Regular.otf       (or .woff2)
    MohrRounded-Medium.otf        (or .woff2)
    MohrRounded-SemiBold.otf      (or .woff2)
    MohrRounded-Bold.otf          (or .woff2)

## Easiest way to get them in

1. In Google Drive, open Branding and Guidelines, then Font, and download Mohr.zip.
2. Double-click Mohr.zip to unzip it.
3. Copy the six OTF files into this folder, renaming to the names above. The
   originals are named like "Latinotype - Mohr Rounded Regular.otf", so
   "Regular" maps to MohrRounded-Regular.otf, "SemiBold" to MohrRounded-SemiBold.otf,
   and so on.

Tip: if any weight is missing, the app uses the nearest available one, so even
just Regular, Medium and Bold will look great.

## Licence

Mohr Rounded is a paid Latinotype font. Using it as a webfont on a public site
needs a webfont licence. This is the Monday open question. If the licence does
not cover web embedding, remove these files and the app reverts to Nunito.
