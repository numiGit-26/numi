# numi Arcade

A collection of beautifully designed browser games that showcase the numi brand, delight visitors, and demonstrate modern engineering and AI.

**Project One: numi Pong.** Classic Pong mechanics with premium, modern execution. The first game in a growing arcade, built to feel closer to Apple, Linear, Stripe and Raycast than a retro toy.

> "I came here expecting a recruitment company. I didn't expect this. These people clearly love technology."

## Status

Pre-build. We are in the planning phase. No game code has been written yet, by design. We think first and build second.

## Vision

numi Pong is Version 1 of a much bigger idea: **arcade.numi.com**. Visitors play games, compete on leaderboards, unlock achievements, and discover careers and engineering content along the way. Distinctive, memorable, and aligned with the modern, product-minded audience numi works with.

Future games on the roadmap: numi Snake, numi Breakout, numi Asteroids, numi Tetris, numi Space Invaders, numi Memory, numi Minesweeper, numi Word Game, numi Trivia, numi Coding Challenge.

## Planned stack

React, TypeScript, Vite, Tailwind, HTML5 Canvas. Deployed on Vercel. Local-first for V1, architected so a cloud leaderboard plugs in later with no rework.

## Brand

Built on the Super numi identity. Core palette: deep navy `#051C2C`, numi teal `#00AEC7`, numi yellow `#FCE300`, navy mid-tones `#0D3352` and `#0A3A55`, white. Official numi typography to be added.
